# Rule of 72 Multi-Agent Financial System

A multi-agent AI system that teaches and applies the Rule of 72 for financial education.

## Features
- **3 specialized agents**: Calculator, Educator, Conversation Manager
- **Rule of 72 formulas**: T=72/R and R=72/T
- **Visualization**: Investment growth charts
- **Memory**: Removes conversation context
- **Comparisons**: Multiple interest rate analysis

## Installation
```bash
pip install -r requirements.txt
```
**Make sure to replace the variable at line 25 in main.py with your OpenAI API key when running.**
